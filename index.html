04-2 GOVERNANCE & OPS · ON-DEVICE LLM

Inference on the device, without the cloud.

Cloud inference
Tied to the network
and token cost
  • Does not work in air-gapped, underground or remote sites
  • Queries leave for an external server
  • API cost scales linearly with usage
  • Network latency dictates response time
On-device LLM
Under 1GB SLM —
it ends on the device
  • Fully offline · syncs overnight only
  • More than 90% of tasks handled on-device
  • About 1/10 the cost of cloud
  • Extends to mobile on-device RAG
